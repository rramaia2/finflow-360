# Definition of Done

A story is done when:

- Acceptance criteria are satisfied.
- Code has been reviewed.
- Unit and integration tests pass.
- Test coverage meets the required threshold.
- API and event contracts are updated.
- Authentication and authorization are verified.
- Logs include correlation IDs.
- Sensitive values are not logged.
- SonarQube quality gates pass.
- Deployment configuration is updated.
- Documentation and runbooks are updated.
- The feature is demonstrated in the staging environment.
