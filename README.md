# FinFlow 360

FinFlow 360 is a cloud-native payment and settlement platform built to
demonstrate reliable financial transaction processing.

## Planned technology stack

- Java and Spring Boot
- React, Next.js and TypeScript
- PostgreSQL and DynamoDB
- Apache Kafka and Redis
- AWS and Terraform
- Docker, Kubernetes and OpenShift
- Jenkins, GitHub Actions and SonarQube
- JUnit, Mockito, Jest and Cypress

## Core workflow

Payment Intake -> Kafka -> Settlement -> Reconciliation -> Operations

## Current status

Phase 1: Discovery and requirements
